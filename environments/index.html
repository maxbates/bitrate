design notes · source on GitHub · play drum pad

This is a research game. It records what you selected and when — timing and accuracy — to measure how fast a person can push information through an interface. Selection timing is quasi-biometric. There are no accounts, no names, and no personal information: a player is a random id in your own browser's storage, shown as a pseudonym.
